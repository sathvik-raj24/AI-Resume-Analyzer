# ✦ AI Resume Analyzer

An AI-powered resume intelligence system built with **Python and Streamlit** that helps candidates understand how well their resume matches a target job description.

The application analyzes resume content, extracts relevant skills, identifies keyword and skill gaps, evaluates ATS compatibility, and provides actionable recommendations for improving the resume.

---

## 🚀 Features

### 📄 Resume Analysis

- PDF resume parsing
- Resume text extraction
- Resume section detection
- Contact information extraction
- Email detection
- Phone number detection
- LinkedIn detection
- GitHub detection

### 🧠 Skill Intelligence

- Automated skill extraction
- Categorized skill detection
- Smart skill synonym matching
- Canonical skill normalization
- Resume skill identification
- Job-required skill identification
- Matching skill detection
- Missing skill identification

### 🎯 Job Matching

- Resume vs. job description comparison
- NLP-based text similarity
- Skill match score
- Keyword match score
- Experience relevance analysis
- Job-specific skill gap identification
- Keyword gap analysis

### 📊 ATS Analysis

The application provides a **heuristic ATS evaluation** based on multiple resume characteristics.

The ATS analysis includes:

- Overall ATS score
- Skill match score
- Keyword match score
- NLP similarity
- Experience relevance
- Resume structure score
- Contact information score
- Resume section checks
- Additional ATS compatibility checks

> **Important:** The ATS score generated by this project is a heuristic estimate. It does not represent the scoring algorithm used by any specific company's ATS.

### ✍️ Resume Improvement

The system analyzes resume bullet points and identifies:

- Weak phrases
- Weak bullet points
- Achievement-oriented bullets
- Quantifiable metrics
- Missing resume sections
- Areas requiring improvement
- Missing job-specific keywords
- Missing technical skills

It then generates actionable recommendations to improve the resume.

### 💼 AI Cover Letter Generator

Generate a tailored cover-letter draft using:

- Resume information
- Target job description
- Matching skills
- Missing skills
- Target role
- Company name

The generated letter can be downloaded as a text file and customized before use.

### 📑 PDF Report

Generate a downloadable resume analysis report containing the major analysis results.
